Getting Started

🔗 Connect Your Wallet

Use the Connect Wallet button in the top-right header. The Start Auto Swap button stays disabled until a wallet is connected — this is intentional because all swaps are signed directly from your wallet.

🏘️ Select a Community

The dropdown at the top of the card lets you choose which community receives a share of the swap fees. You must select one to unlock swapping. This can be changed any time before starting.

💡 The Active Vault pill below the selector shows exactly where fees are routed for the currently selected input token.

🧮 Plan with the AutoSwap Math Estimator

The estimator helps you work backward from a total amount, swap count, or time window into AutoSwap settings to consider entering. It is a planning tool only: it does not connect to a wallet, read balances, request quotes, execute swaps, or apply settings automatically.

Where to Find It

On desktop, open the estimator panel beside the AutoSwap form. On smaller screens, select AutoSwap Math Estimator below the Swap and Auto Swap tabs to open the drawer.

You can also use the standalone calculator at aquavaults.com/autoswap/estimator. Both versions use the same calculation rules.

1. Enter the Amount and Pair

Enter the Total amount to use, then choose the From token and Swap into token. Preset tokens are available immediately, and custom Solana tokens can be found through Search / Manage Custom Tokens.

💡 Enter only the amount you are prepared to use. The estimator does not inspect your wallet balance.

2. Choose How to Build the Plan

Select Number of swaps if you already know the transaction count. The estimator divides the total amount across that count, and you enter either a fixed wait or the Random Wait minimum and maximum you are considering.

Select Time available if you know how long the session should run. The estimator works backward into a suggested swap count, amount, and wait setting.

💡 Time-based plans use approximately 85% of the entered window for configured waits and leave approximately 15% as planning room for transaction processing and confirmation. Actual completion time is not guaranteed.

3. Review Optional Features

  • Random Amount offers Almost the same, A noticeable mix, A wide mix, or exact minimum and maximum amounts. Preset ranges keep the calculated amount as the maximum, so the final total used may be lower than the amount entered.
  • Random Wait calculates a range automatically in time mode. In swap-count mode, enter the minimum and maximum wait values you want to evaluate.
  • Flip-Flop counts both forward and reverse transactions. Reverse amounts depend on what the preceding forward swap actually returns and cannot be predicted exactly.
  • Add more swap pairs includes Pair 2 and an optional Pair 3. Their amounts are separate from the base-pair calculation, and you must have enough of each additional starting token.
💡 There is no configured wait after the final transaction. For example, 20 swaps contain 19 waits.

4. Calculate and Enter the Settings

Select Estimate AutoSwap values. Review the suggested amount, number of swaps, wait settings, optional-feature details, and calculation notes. You can copy the result as a text summary.

The estimator does not apply the result. Return to AutoSwap and manually enter each setting after reviewing it.

Example: 10 USDC over 1.5 Hours

With 10 USDC, a 1.5-hour time window, and Random Amount, Random Wait, and Flip-Flop turned off, the estimator suggests:

  • Amount: 0.625 USDC
  • Number of Swaps: 16
  • Wait After Swap: 300 seconds

The 16 swaps contain 15 configured waits, or approximately 75 minutes of waiting, leaving approximately 15 minutes of planning room outside those waits.

⚠️ Estimator results are mathematical planning values, not swap quotes or predictions. Prices, slippage, network fees, liquidity, confirmation time, failures, random selections, and Flip-Flop execution can make actual results materially different. Review every AutoSwap field and every wallet prompt before proceeding.

⚙️ Swap Settings

Click the ⚙️ Swap Settings bar to expand these controls. They persist across sessions — set them once and they'll be remembered.

💰 Platform Fee

The percentage fee charged by AquaVaults per swap (separate from Solana network fees or DEX fees). Defaults to 1.0%. Range: 0% – 10%. Fees route to the selected community's configured treasury accounts based on the token and routing path used.

💡 Always check your wallet prompt before signing — it will show exactly what is being deducted.

📊 Slippage

Defaults to 1.0%. A lower value gives you better rates but may result in possible failed transactions. A higher value may increase transaction success but could result in a worse execution price.

⚡ Priority Fee

An extra fee (in SOL) paid directly to Solana validators to get your transaction confirmed faster during congestion. Options:

  • Auto — lets the network decide (recommended for normal conditions)
  • Low congestion / Moderate / Elevated — fixed presets in SOL
  • Custom — enter your own SOL amount

🔄 Swap Pair (Pair 1)

This is the primary token pair that every AutoSwap run will use. It is always active — the optional pairs below only come into play if you enable 🔀 Random Swap Pairs.

From / To Tokens

Use the From and To dropdowns to choose your token pair. The balance for each is shown below its selector and refreshes after each swap. You can use a custom token by selecting 🔍 Search / Manage Custom Tokens from the dropdown.

Amount

The amount of the From token to spend on each swap. For example, setting 0.5 with SOL as the From token will spend 0.5 SOL per swap. If 🎲 Random Amount is enabled, this fixed value is overridden.

🎛️ Auto Swap Configuration

Number of Swaps

How many swaps to execute in total before the run finishes automatically. Range: 1 – 1000. The run will stop early if you press Stop or if a swap fails.

Wait After Swap (sec)

How many seconds to pause between each swap. Progress is shown in the Countdown status line. If ⏱️ Random Wait Time is enabled, this fixed delay is overridden.

🔁 Flip-Flop

When the Flip-Flop toggle is on, AutoSwap automatically reverses the direction of the trade after each swap. For example:

Swap 1: SOL → USDC ↓ Swap 2: USDC → SOL ↓ Swap 3: SOL → USDC ↓ …and so on

This is useful for cycling liquidity between two tokens continuously without manually reconfiguring the pair between runs.

💡 Flip-Flop uses the same token pair as Pair 1 — no extra configuration needed.

✨ Optional Features

Each feature below is collapsed by default. Click its header row to toggle it on or off. When enabled, the section expands to reveal its settings.

⏱️ Random Wait Time

Instead of a fixed delay, AutoSwap will wait a random number of seconds between each swap, chosen from your range. Useful for introducing more variability into automated activity patterns.

Min Wait Shortest possible pause (seconds)
Max Wait Longest possible pause (seconds)
💡 When this is on, the Wait After Swap value above is ignored.

🎲 Random Amount

Instead of a fixed amount, each swap will use a random amount drawn from your range. The swap will only execute if your wallet has enough balance for the selected amount.

Min Amount Smallest amount that can be swapped
Max Amount Largest amount that can be swapped
💡 When this is on, the fixed Amount in Pair 1 is ignored.

🔀 Random Swap Pairs

Add up to 2 additional swap pairs (Pair 2 and Pair 3). Each swap in the run will randomly pick one of the enabled pairs to execute. This lets you rotate activity across multiple token combinations automatically.

Each additional pair has its own:

  • From / To tokens — chosen from the same token list as Pair 1
  • Amount — can be different for each pair
  • Random checkbox — enables a min/max range for that pair's amount specifically
💡 Pair 1 is always included in the random selection. Set Pair 2 and/or Pair 3 From to -- None -- to disable them.

▶️ Running a Session

📋 Check Settings

Press 📋 Check Settings before starting. This validates your entire configuration and prints a summary to the Activity Log — token pairs, amounts, swap count, features enabled, and estimated fees. Fix any warnings before proceeding.

▶ Start Auto Swap

Press Start Auto Swap to begin the run. Your wallet will prompt you to sign each transaction — review and approve each one individually. The Status and Countdown lines update in real time so you can track progress.

⚠️ Never approve a wallet prompt if the amounts or tokens shown don't match what you configured.

⏹ Stop

The Stop button appears once a run is in progress. Pressing it halts the sequence after the current swap completes — it will not cancel a transaction already submitted to the network.

🖱️ Hands-Free with a Clicker

Want a more hands-free setup? Some users choose to pair AutoSwap with external automation tools to assist with repetitive wallet confirmation prompts during long-running sessions.

You can use a publicly available auto clicker, or check out the Windows and Mac PyAutoGUI repos linked below if you want a more customizable setup.

These tools may interact with wallet prompts or other screen elements automatically if configured incorrectly or left running unattended. You are fully responsible for reviewing and approving every transaction submitted from your wallet.

🖥️ Activity Log

The panel below the swap card records every action in real time.

Log Entries

Each line is color-coded: success for confirmed swaps, error for failures, info for status updates, and warning for non-critical issues.

Stats Bar

The footer of the log shows running totals for Total, Errors, Warnings, and Success counts at a glance.

Controls

🗑️ Clear wipes the display. 💾 Export downloads the full log as a text file — useful for reviewing a completed run or reporting issues.
