Embedded Solana Swaps

Swap Widget

Bring AquaVaults manual Solana swaps directly onto your website. Listed projects use the approved integration when campaign and Rewards eligibility matters. Anyone can use the Public Swap Widget without listing first.

Two Integration Paths

AquaVaults provides two ways to embed its Solana swap interface. They look similar to users, but they serve different purposes and are not interchangeable.

Listed Project: Approved Widget

For projects already listed on AquaVaults. Use the private integration documentation supplied during onboarding and have the production website origin approved. This is the integration path intended for eligible community campaign activity and AquaVaults Rewards participation.

Any Website: Public Swap Widget

For any website that wants to add AquaVaults manual Solana swaps. No listing, AquaVaults API key, or per-domain approval is required to get started. Public-widget swaps are not eligible for AquaVaults Rewards or approved community campaign credit.

Choose the Integration Before You Launch

If your project is already listed, do not use the public integration as a substitute for the approved widget. Use the approved integration documentation so your site is recognized through the approved SDK path. Normal campaign rules and Rewards qualification requirements still apply.

Listed Projects: Use the Approved Widget

After a project is listed on AquaVaults, its embedded widget can become part of the same participation system as the rest of the platform. The important step is using the approved widget integration rather than the unrestricted public version.

The approved integration is provided through AquaVaults' private widget documentation. The project's production website origin is approved, the widget is configured for the listed community, and qualifying activity can be recognized as approved widget activity.

Community Campaign Activity

Use the approved integration when embedded swaps need to count as eligible widget activity in AquaVaults community campaigns. Campaign-specific rules still determine which swaps and actions qualify for each campaign.

User Rewards

Qualifying swaps made through the approved widget can earn AquaVaults Rewards points for enrolled users. The normal Rewards requirements still apply, including the qualifying-swap rules; embedding the widget does not bypass them.

Approved Site Recognition

The approved production origin identifies the project website as an authorized widget integration. This is part of keeping approved widget activity separate from unrestricted public-widget activity.

Community Configuration

The approved integration documentation covers the configuration available to listed projects, including community-specific setup and the controls supported by that integration.

Already Listed?

Use the private approved-widget documentation supplied by AquaVaults and make sure the exact production website origin has been approved before relying on embedded activity for campaign or Rewards eligibility.

Public Swap Widget: Public Website Integration

The AquaVaults Public Swap Widget removes the listing requirement for basic website integration. A project, community, developer, token site, or other website can embed a working AquaVaults manual Solana swap interface without first becoming an AquaVaults-listed project.

The public integration is designed to be straightforward: load the hosted widget, place a container where the swapper should appear, and mount it. The public bundle is standalone and does not require the host site to supply AquaVaults, Jupiter, or RPC-provider credentials.

Public Repository

The complete public integration guide, working examples, configuration reference, wallet-adapter examples, deep-link documentation, styling options, runtime API, callbacks, security guidance, and troubleshooting guide are available in the AquaVaults Public Swap Widget repository. The repository contains integration documentation and example code; the hosted AquaVaults widget itself is served by AquaVaults.

What the Public Widget Can Do

Manual Solana Swaps

Users can connect a Solana wallet, select tokens, review a swap, sign it, and complete the transaction without leaving the host website.

Built-In or Existing Wallet Flow

A site can use the widget's built-in wallet connection or integrate the widget with an existing Solana wallet connection using the documented wallet adapter interface.

Community Selection

The host can configure an AquaVaults-listed community and may lock that selection. When applicable, community fee routing follows AquaVaults' current routing rules. Embedding the public widget does not create a community listing.

Deep Links

Buy or sell token mints can be preloaded through supported deep-link parameters, making it possible to build direct token and campaign landing-page flows.

Website Styling

Documented CSS variables allow the widget to better match the surrounding site's visual design without modifying the hosted widget source.

Runtime Controls and Callbacks

The public documentation includes supported runtime methods and callbacks for sites that need deeper integration with their own interface.

What the Public Widget Cannot Do

The Public Swap Widget is intentionally separate from the approved integration used by listed projects. Public availability does not grant the campaign and Rewards status associated with an approved website integration.

No AquaVaults Rewards Eligibility

Swaps made through the Public Swap Widget are not eligible for AquaVaults Rewards points. A listed project must move its site to the approved integration path if it wants qualifying embedded activity to participate in Rewards.

No Approved Campaign Credit

The public integration is not the approved community-campaign path. Projects that need embedded activity recognized for eligible AquaVaults community campaigns should use the approved widget integration after listing.

No Listing Benefits Just for Embedding

Installing the Public Swap Widget does not list the host project on AquaVaults and does not create a community fee share. A project must be listed separately to receive the benefits attached to an AquaVaults community listing.

No Host-Locked Public Fee

The public widget opens with its public fee setting and the user can adjust it. The host website cannot use the public configuration to lock or replace that opening fee.

No AutoSwap, Limit Orders, or EVM Swaps

The Public Swap Widget is a manual Solana single-swap interface. AutoSwap, Trigger/limit orders, EVM swaps, and administrative tools are separate AquaVaults products and are not exposed through this public widget.

Public Widget Quick Start

The public integration requires three basic pieces. The GitHub repository contains the full documentation and complete working examples.

1. Load the Public Swap Widget

Add the hosted script inside the page <head>:

<script src="https://aquavaults.com/sdk/aquavaults-sdk-open.js"></script>

2. Add the Widget Container

Place this element wherever the swap widget should appear:

<div id="swap-widget"></div>

3. Mount the Widget

After the container exists on the page, mount the widget:

<script>
  AquaVaultsSDK.mount('#swap-widget', {
    apiBase: 'https://aquavaults.com'
  });
</script>

That is the minimum integration. Community configuration, token defaults, deep links, styling, existing-wallet integration, callbacks, and runtime controls are documented in the public repository.

Fees and Community Routing

The public widget opens with a 1% platform fee. The user can adjust the fee from the widget; the embedding website cannot lock or override the public widget's opening fee.

A host may configure or lock the selected AquaVaults-listed community. When an eligible listed community is selected and a platform fee is generated, fee routing follows AquaVaults' current community routing rules. A project must be listed to receive a community share; embedding the Public Swap Widget does not itself create a listing or make the host website an approved integration.

AquaVaults' Community Growth Program applies to platform fees that swaps actually generate. It does not guarantee swap volume, revenue, rewards, rankings, campaign access, or token performance.

Deep Links and Prepared Swap Flows

The Public Swap Widget supports URL parameters that can preload the token a user is buying or selling. This allows a site to create dedicated token pages, announcement links, or other prepared swap flows without removing the user's control over execution.

A deep link prepares the interface. It does not execute a transaction. The user still connects their own wallet, reviews the swap, and signs the transaction themselves.

https://your-site.example/swap?av_buy=TOKEN_MINT
https://your-site.example/swap?av_sell=TOKEN_MINT

See the repository's deep-link guide for the supported behavior and complete examples.

Starting Public, Then Listing Later

A site can start with the Public Swap Widget before it is listed on AquaVaults. If the project later becomes listed and wants its embedded activity to participate in the approved campaign and Rewards paths, the existing public widget does not change status automatically.

1. Get Listed

Complete the AquaVaults listing process and receive the project's listed community configuration.

2. Approve the Production Origin

Provide the exact production website origin that will host the approved widget so AquaVaults can onboard it to the approved integration path.

3. Use the Private Integration Docs

Replace the public-widget integration with the approved widget setup supplied by AquaVaults. Do not assume that changing only the community setting makes the public widget approved.

4. Validate Before Campaigning

Confirm the approved widget is running from the intended production origin before relying on it for eligible campaign activity or telling users that qualifying swaps can participate in AquaVaults Rewards.

User Control and Non-Custodial Design

AquaVaults is non-custodial. You connect your own wallet, you control your own funds at all times, you choose your own fee level on each swap, and you decide whether to participate. AquaVaults never takes custody of user funds.

Users Connect Their Own Wallet

The widget does not give the host website custody of user funds or signing authority over the user's wallet.

Every Swap Is User-Approved

Preloaded tokens, community settings, and deep links do not bypass wallet approval. Users still review and sign their own transactions.

Third-Party Infrastructure

AquaVaults relies on third-party services and networks it does not control, including swap routing, wallets, RPC/data providers, and the Solana network. Their availability, pricing, and behavior can change.
